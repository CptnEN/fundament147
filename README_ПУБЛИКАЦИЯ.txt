ФУНДАМЕНТ 147 — готовая статическая версия сайта

Структура:
- index.html — главная страница
- семь HTML-страниц услуг
- articles.html — каталог статей
- articles/ — одиннадцать статей, пробное бурение расположено первым
- images/ — изображения
- style.css — общие стили сайта и единое оформление статей
- robots.txt и sitemap.xml — технические SEO-файлы

Для публикации на GitHub Pages загрузите содержимое этой папки в корень репозитория (не саму папку SpecSvai).
Текущие canonical, robots.txt и sitemap.xml настроены на адрес GitHub Pages:
https://cptnen.github.io/fundament147/

Когда будет подключён собственный домен fundament147.ru, необходимо будет единообразно заменить основной адрес в canonical, Open Graph, robots.txt и sitemap.xml на окончательный домен.

Важно о форме заявки: сайт статический. Форма подготовлена как mailto-заявка: после заполнения и нажатия кнопки открывается почтовая программа с готовым письмом, которое посетитель отправляет вручную. Это не автоматическая серверная отправка. Для автоматического приёма заявок потребуется подключить и подтвердить внешний обработчик или серверную функцию.

Контактные данные в страницах не изменялись.
